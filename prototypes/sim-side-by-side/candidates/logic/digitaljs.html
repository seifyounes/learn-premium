For the Owner

  • Real: DigitalJS 0.14.2 exactly as shipped (dist/main.js), running the same full-adder JSON as the circuit prototype (circuits/logic/digitaljs.json). Nothing is re-skinned. The strip above reads the tool's own outputs through its API; it is ours, not DigitalJS's.
  • Weight: about 2.5 MB on first load, measured in the browser (main.js alone is 2.33 MB; this dev server sends it uncompressed, gzip would make it about 0.7 MB), plus 145 KB of pad fonts every page shares. One file bundles jQuery, Backbone, JointJS and the ELK layout engine.
  • Touch: partial. At phone width the drawing stays at 1x and scrolls sideways inside its frame; the input buttons are about 25 px and the gate and pin labels are under 12 px. Gates drag, so a finger can move one by accident.
  • To ship: the jQuery/JointJS look would need restyling to sit on the pad; auto-layout places gates differently from the Professor's figure; far too heavy for a phone-first study site unless lazy-loaded.
