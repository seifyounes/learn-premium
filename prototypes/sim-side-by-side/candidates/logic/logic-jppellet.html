Tap an input (A, B, Cin) to flip it between 0 and 1; outputs S and Cout follow. The round-arrow button in the tool's corner is its own reset. The embed runs in the tool's tryout mode, the one meant for students (no editing).

For the Owner

  • Real: the current Logic build (bundle.js from logic.modulo-info.ch, dated 2026-07-30, MIT), copied to vendor/logic-jppellet/. The full adder was hand-authored in its JSON5 format for this page (same gates and nets as the other candidates); positions are ours. Not re-skinned. The strip above reads the tool's live outputs; it is ours.
  • Weight: about 1.1 MB on first load, measured in the browser: the 817 KB bundle (about 250 KB gzipped; this dev server sends it uncompressed), plus 158 KB of Bootstrap 4 CSS that the bundle itself fetches from jsDelivr, plus 145 KB of pad fonts every page shares.
  • Touch: partial. Tapping an input works, but to fit a phone the tool's zoom drops to about 40%, so the input circles are roughly 10 px and the names are tiny.
  • To ship: its API is thinly documented and the project is small (one maintainer); it has propagation-delay animation, hidden-component exercises and circuit tests we have not tried here.
