What a student has to do
  1. Empty the diagram (blank-page icon), then drag three rungs from the toolbox.
  2. Drag in contacts, coils and a TON; add a branch under START for the seal-in.
  3. Create bool tags START, STOP, M1, M2 and a timer T1 (preset 5000) in the tag table; assign them.
  4. Press the green run button, set STOP to 1 (the NC button at rest), then toggle START on and off in the tag table.

For the Owner

  • Real vs faked: nothing is faked; this is the public app (app.plcsimulator.online) in an iframe (no X-Frame-Options or CSP, checked with curl). The program is not loaded: the site only opens diagrams from its own cloud share links (sign-in required to create one) and has no file import, so it opens on its own sample or your last diagram.
  • First load: about 1.39 MB over 56 requests at desktop size (1.27 MB on a phone), about a third of it AdSense and Google Tag Manager running inside the frame, plus a 60 KB handwriting font for its hints.
  • Touch: the site has a phone layout, but rungs are built by HTML5 drag and drop, which mobile browsers mostly ignore; toggling tag values and simulating work by tap.
  • Maintenance: the app now shows a banner from its author: he no longer develops it and points students to studio.rungs.dev (closed).
  • Accuracy: not checked here (program not loaded). Research: Rockwell-style TON/TOF/TONR/CTU/CTD with a fixed 66 ms scan; no TP; its TOF counts ET down, which is not IEC.
  • To ship: fork it (GPL-3.0), strip Firebase, ads and analytics, and add a load-from-JSON route so each lecture's program opens ready to run.
