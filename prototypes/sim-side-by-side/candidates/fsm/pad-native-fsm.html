For the Owner

  • Real: every table, equation, state and Z on this page comes from pad-native-fsm.engine.mjs stepping the machine in machine-101.mjs; nothing is typed into the view. The engine also minimises D1, D0 and Z itself. check-pad-native-fsm.mjs runs it in Node against the hand-written key (machine.md): 49 of 49 PASS, including the test sequence (Z after each edge 0 0 1 0 1 0 0 1).
  • Hand-placed: the diagram's state positions and arrow bends are fixed coordinates for this one machine. A real build would lay out any machine with elkjs or dagre at build time, then check that labels do not collide.
  • First load: 196 KB cold, measured over CDP from the local server (uncompressed), of which about 140 KB is the three pad fonts. The page code is about 45 KB; no libraries, the motion is the Web Animations API.
  • Touch: works. Every control is at least 48 px tall and nothing needs hover or drag; a CDP touch tap on CLOCK in an emulated 390 × 844 phone clocks the machine. Not tried on a real phone. Keys on a laptop: 0 / 1 set X, C clocks.
  • To ship: an auto-layout step for other machines, a Mealy view (outputs on the arrows), a JK/T flip-flop option in the UI (the engine derives both, untested), and an accessibility pass on the SVG.
