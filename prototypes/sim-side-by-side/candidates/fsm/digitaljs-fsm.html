DigitalJS numbers the states: 0 1 2 3 are S0 S1 S2 S3. Its FSM cell is Mealy (output on each arrow), so each arrow out of a state carries that state's Z: arrows read input/output, and only the two arrows leaving state 3 say /1.

For the Owner

  • Real: DigitalJS 0.14.2 as shipped (its own look, dagre graph, monitor), loading an agent-written circuit (digitaljs-fsm.json). The page adds only the Pause / Show graph buttons and places DigitalJS's graph popup inline instead of in a jQuery dialog.
  • Accuracy: check-digitaljs-fsm.mjs runs this FSM cell headless in Node (Clock swapped for a Button so the check can clock it): the test sequence and all 8 state-table entries, 20 of 20 PASS. So the FSM cell does run in HeadlessCircuit.
  • Moore, bent to fit: the cell is Mealy only, with numbered states and no state names or state outputs; Z is written on every arrow leaving a state. There is no state output wire, so the monitor cannot show the state.
  • First load: 2,490 KB cold from the local server (uncompressed; gzip would shrink it, not measured), 2,333 KB of it the DigitalJS bundle.
  • Touch: partial. A CDP touch tap on the X button toggles it, but the button face is 18 px; the circuit does not fit a 390 px phone (it scrolls inside its frame) and the monitor's own controls are small.
  • To ship: a re-skin (fonts, colours, arrows), a manual clock, state names, and a way to keep the graph from re-laying out differently per machine.
