Every REAL on this page is a float32. The first choice shows the shortest decimal that reads back as the same float32, as a STEP 7 watch table does; the second shows ten digits of the stored value.

Tank volume in STL

A horizontal cylindrical tank: raw level from PIW 256, scaled by FC105, turned into litres with ACOS and SQRT, then a register-indirect loop over four set-points and latched alarms.

Warehouse state machine in SCL

A function block called once per scan. Its statics keep the state between scans; the rack is a global data block holding a 2 × 3 array of a slot type.
